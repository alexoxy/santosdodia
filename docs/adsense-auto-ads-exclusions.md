# AdSense Auto ads page exclusions

When Auto ads are enabled in the AdSense console, keep the following URL patterns excluded unless a later policy review explicitly changes them:

- `/calendar`
- `/explore`
- `/day/*`
- `/live`
- `/privacy`
- `/terms`
- `/faq`
- `/corrections`
- `/about`
- `/advertising`
- `/developers`

Reason: these are utility, live/video, consent/legal or low-editorial-value surfaces where automatic placement can interfere with controls or weaken the content-first experience.

The application additionally keeps manual units limited to the homepage and reviewed saint biographies. Auto ads are managed by Google after the publisher code is active, so this exclusion list must also be configured in the AdSense UI.
